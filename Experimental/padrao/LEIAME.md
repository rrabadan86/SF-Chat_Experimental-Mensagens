# Padrões de uma unidade NOVA

Arquivos que uma unidade recém-instalada recebe sozinha na primeira vez que o
sistema sobe (só quando ela ainda não tem os seus):

- `mensagens-fotos.json` — imagens das mensagens prontas do robô (WhatsApp →
  Configuração). É o mesmo arquivo do botão **⬇️ Baixar as imagens desta unidade**
  do painel: baixe da unidade-modelo e substitua este arquivo para atualizar o padrão.
  Copiado para `data/mensagens-fotos/` só se essa pasta ainda não existir.

As tags padrão ficam em `../tags-config.default.json`.
